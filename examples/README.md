# Hands-on exercises

1. Run the `demo` command to create a synthetic card and package.
2. Run `inspect`: discover the catalog and favorite flag.
3. Run `plan`: confirm that no files are changed by planning.
4. Run `backup` twice: see the `created` and `reused` statuses.
5. Run `ai-review` with and without your own API key.
6. Run `apply` with and without `--execute` and exact confirmation.
7. Run `restore` against the verified backup.
8. Inspect `game/games.db` in a SQLite viewer, and observe favorite preservation.

**All exercises use the disposable local demo card.**
